Памятка: приставки и суффиксы. Если нет нужной формы — можно образовать от существующей (косяк автора, извините). Глаголы: окончание -t. Если основа на t/k/w/d перед -as → добавить -t; если -s после согласного → тоже -t. От сущ. к глаголу: +t / +it. Желательно не -as→t, если ситуация неподходящая. Наречия: -as→-ai, -is→-i (или убрать окончание / добавить к -s).

6. Наречия

Прил. на -as → наречие на -ai (tikras → tikrai). На -is и др. → заменить на -i (akrotis → akroti). Можно убирать окончание или добавлять к -s.

Сложение основ

Убираем as/s до согласного, вставляем o: Aū + okrisas → Aūokrisas; Wardotwarkīsna (словообразование).

Степени сравнения (кратко)

Weigli → Weiglisāk; Buni → Bunisāk; Deringas → deringasāk. Превосходная: приставка wis-.

1. Местоимения

Личные: As (я); Tu / Es / Esa (ты / он / она — одна глагольная форма); Mes (мы); Esai (они / вы, также jūs).

Указательные / вопросительные: Taso (это), Tas (этот), To/tos/tosa/tosai; Kit (кто), Kar (что), Kai (как), Kawīdas/kawīdasa/kawīdasai; Kuei (где), Ikai (если), Kan (когда); Karim … per; Su tasim; Taip, Pats, Erains, Mans, Mesuns, Jūsuns, Tusuns.

2. Существительное

2.1 Слова на -o (walājo, to) — формально ж.р., используются для среднего (отдельного среднего рода нет).

2.2 Склонение wiros / wirba

Если прилагательное / сущ. от прилагательного — as (и иное) убирается в м.р.: kritiskasios, но kritisko. Во мн.ч. м. и ж. через «/». Винительный можно заменять родительным при одушевлённости / ясности контекста (м.р.).

2.3 Множественное число: убираем as, is, es, os, s → ставим ai (если не остаётся всего две буквы).

2.4 Порядок: указательное + числительное + прилагательное + существительное: tosai tris wargan tiltanan.

2.5 Этнонимы: Prūsija → prūsas / prusiskas; Slāwija → slāwas / slāwiskas.

4. Порядковые числительные

Pirmas, duotas, tritas, tetertas, panktas, šiatas, geptitas, aktitas, newineitas, desimtitas, sentas — убираем -s, ставим -tas.
