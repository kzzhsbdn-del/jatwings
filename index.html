Памятка суффиксов

  • -umas ≈ «-ость»: drasus → drasusumas (смелость)
  • -ums — абстрактное сущ. (от прилагательных) и результат глаголов
  • -sna ≈ процесс «-ние/-тие»: skaitisana — чтение
  • -uwas / -duwas — прибор (отглагольное): sauduwas — ружьё
  • -manas — любитель: arbatamanas — любитель чая
  • -īkas — профессия, род занятий
  • -inis / -iskas — прилагательные от существительных (м.р. / ж.р.): Kompiuteris → Kompiuterisinis
  • -nica — хранилище / помещение: Wardnica, Gastisnica
  • -ejas — «-тель / -щик»

1. Образование глаголов

Формула: Существительное + d → глагол

Если глагол только с d (без гласной) — можно -as вместо d; иначе -id. От существительных: прикреплять id/d. abminas → abmind · sens → sensd · rada → radid · milda → mildad · ilgas → ilgasd

Желательно не всегда ставить -as в d, если ситуация не подходит. Несколько вариаций допустимы.

6. Наречия

От прилагательного: добавить -i (если гласный до s), иначе заменить s на i. Также можно убирать окончание или добавлять к -s.

tikras → tikrasi · akrotis → akroti · Weigli → Wieglisāk · Buni → Bunsāk · Deringas → deringasāk

7. Причастия / деепричастия

  • Сделан/готов: убрать -d, добавить -tas/tasa/taso → izraditas / izraditasa / izraditaso
  • Читаемый: skaitidsama (ж.), skaitidsams (м.)
  • Прочитанный: iz/ap-skaitid-ts / skaitid-tsa
  • Читавший: skaitid-is / skaitid-isa
  • Деепричастия: добавить ot (сов. вид — с приставкой)
